# Support

## How to Get Help

This repository contains step-by-step Intune guides for admins and end users. Support options are listed below.

### 📖 Documentation

- [Microsoft Intune documentation](https://learn.microsoft.com/mem/intune/)
- [Microsoft Endpoint Manager blog](https://techcommunity.microsoft.com/t5/microsoft-intune-blog/bg-p/MicrosoftIntuneBlog)

### 🐛 Issues with the Guides

If you find an error, an outdated step, or unclear instructions in one of the guides, please [open a GitHub Issue](../../issues/new/choose) and include:

- The guide name and section
- What the problem is
- What the correct information should be (if known)

### 💬 Community Support

- [Microsoft Tech Community – Intune](https://techcommunity.microsoft.com/t5/microsoft-intune/bd-p/Microsoft_Intune)
- [Microsoft Q&A – Intune](https://learn.microsoft.com/en-us/answers/tags/415/intune)

### 🔒 Security Issues

Do **not** report security vulnerabilities via GitHub Issues. See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.

---

This project is maintained on a best-effort basis. Microsoft Support does not officially support the contents of this repository.
