# Security Policy

## Supported Versions

This repository contains documentation guides rather than executable software. Security disclosures should relate to the accuracy of security-sensitive instructions (e.g., incorrect policy configurations that could expose data).

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them via the Microsoft Security Response Center (MSRC):

- **Portal:** [https://msrc.microsoft.com/create-report](https://msrc.microsoft.com/create-report)
- **Email:** [secure@microsoft.com](mailto:secure@microsoft.com)
- **PGP Key:** [https://www.microsoft.com/en-us/msrc/pgp-key-msrc](https://www.microsoft.com/en-us/msrc/pgp-key-msrc)

You should receive a response within **24 hours**. If for some reason you do not, please follow up via email to ensure we received your original message.

Please include as much of the following information as possible to help us better understand the nature and scope of the possible issue:

- Type of issue (e.g., incorrect security configuration guidance)
- Location of the affected content (file path and line numbers)
- Potential impact of the issue
- Step-by-step instructions to reproduce the problem
- Proof-of-concept or exploit code (if relevant)

This information will help us triage your report more quickly.

## Preferred Languages

We prefer all communications to be in English.
